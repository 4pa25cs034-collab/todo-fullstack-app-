# REST API Based To-Do Application

A full-stack responsive To-Do web application built with **Node.js**, **Express**, **SQLite**, and **HTML/CSS/JavaScript**.

## Features
- **Create, Read, Update, Delete (CRUD):** Full task management via RESTful APIs.
- **Database Persistence:** Tasks are stored permanently in an SQLite database (`todos.db`).
- **Responsive UI:** Clean, modern design that works smoothly on mobile and desktop.

## REST API Endpoints
- `GET /api/todos` - Fetch all tasks
- `POST /api/todos` - Add a new task
- `PUT /api/todos/:id` - Update task text or completion status
- `DELETE /api/todos/:id` - Remove a task

## How to Run Locally
1. Run `npm install`
2. Run `npm start`
3. Open `http://localhost:3000` in your browser
